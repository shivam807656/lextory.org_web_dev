# Lextory Foundation - Web Platform

Official website and digital educational platform for the **Lextory Foundation**, an independent civic initiative dedicated to open legal literacy, community dialogue, and peaceful dispute resolution across India.

🌐 **Live Website:** [https://lextoryfoundation.org](https://lextoryfoundation.org)  
⚡ **Vercel Mirror:** [https://lextoryorgwebdev.vercel.app](https://lextoryorgwebdev.vercel.app)

---

## 🏛️ About Lextory Foundation

Lextory Foundation works at the grassroots level to demystify Indian law, empower citizens with statutory protections (NALSA, POCSO, Consumer Protection, Cyber Crime Helplines), and encourage alternative and online dispute resolution (ODR).

### Key Initiatives & Portals
- **Civic Literacy & Know Your Rights Guides**: Plain-language legal guides for citizens, students, and seniors.
- **ODR Awareness Centre**: Promoting accessible, cost-effective mediation and online arbitration.
- **Grassroots Legal Aid Camps**: Direct educational outreach across Uttar Pradesh & NCR.
- **Statutory Helplines Directory**: Verified emergency contacts (112, 15100, 1930, 1091, 1915).

## 💻 Tech Stack & Architecture

- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Curated modern CSS Design System with responsive grid architecture
- **Icons:** [Lucide React](https://lucide.dev/)
- **Hosting & CI/CD:** [Vercel](https://vercel.com/) with automated deployments from GitHub `main` branch
- **Custom Domain:** `lextoryfoundation.org` configured via Anycast edge routing

## 🛠️ Local Development

```bash
# Clone the repository
git clone https://github.com/shivam807656/lextory.org_web_dev.git
```
